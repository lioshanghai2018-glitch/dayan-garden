## 一、项目概述

### 1.1 产品名称

**大研菜园**

- 「大研」取自大研古城，融合本地文化特色
- 「菜园」直接表明业务本质，新鲜蔬菜直供
- 口号：大研菜园，新鲜到家

### 1.2 核心价值

| 维度 | 描述 |
|------|------|
| **对客户** | 足不出户买到新鲜本地菜，价格实惠，送货上门 |
| **对商家** | 专注小区用户，订单稳定，损耗低 |
| **对菜农** | 稳定销售渠道，减少中间环节 |
| **差异化** | 比超市更新鲜、比网购更快、比菜市场更方便 |

### 1.3 MVP范围

**Phase 1 必须实现（MVP）**
- 商品浏览与搜索
- 购物车管理
- 下单与模拟支付
- 商家处理订单
- 骑手配送
- 客户签收确认

**Phase 2 增强功能**
- 微信支付
- 优惠券/满减
- 评价系统
- 消息推送

**Phase 3 完整功能**
- 供应商入驻
- 配送路线优化
- 会员体系
- 数据分析

## 二、角色定义

### 2.1 客户（小区居民）

| 属性 | 说明 |
|------|------|
| **身份** | 小程序用户，通过微信授权登录 |
| **核心需求** | 浏览商品、下单购买、查看配送进度、签收 |
| **使用场景** | 早上/晚上在家选菜下单，预留配送时间 |
| **权限** | 管理收货地址、查看订单、管理购物车、评价 |

### 2.2 商家（运营者/管理员）

| 属性 | 说明 |
|------|------|
| **身份** | Web管理后台用户，手机端友好 |
| **核心需求** | 上架商品、管理库存、处理订单、配置配送时间 |
| **使用场景** | 早上去菜市场采购后上架，白天处理订单 |
| **权限** | 商品CRUD、订单管理、配送确认、公告发布、骑手管理、供应商管理 |

### 2.3 骑手（配送员）

| 属性 | 说明 |
|------|------|
| **身份** | 小程序骑手端用户（独立分包） |
| **核心需求** | 领取配送任务、导航到客户、确认送达 |
| **使用场景** | 接到订单后到商家取货，按路线配送 |
| **权限** | 查看待取货订单、配送中订单、配送路线、确认送达 |

### 2.4 供应商（菜农）

| 属性 | 说明 |
|------|------|
| **身份** | 初期由商家代录入，无需独立端 |
| **核心需求** | 提供蔬菜货源 |
| **备注** | MVP阶段不需要独立系统，商家手动录入供应商信息和供货清单 |

### 3.2 各角色详细操作

#### 客户操作流程

| 步骤 | 操作 | 系统响应 |
|------|------|----------|
| 1 | 打开小程序，微信授权登录 | 自动获取用户信息，创建用户记录 |
| 2 | 首页浏览商品/搜索/分类 | 展示商品列表，支持筛选排序 |
| 3 | 点击商品查看详情 | 展示商品图片、描述、价格、单位、库存 |
| 4 | 选择数量，点击"加入购物车" | 购物车数量+1，提示成功 |
| 5 | 进入购物车，确认商品和数量 | 允许修改数量、删除商品，显示总价 |
| 6 | 点击"去结算" | 进入确认订单页 |
| 7 | 选择/新增收货地址 | 地址列表，选择默认或新建 |
| 8 | 选择配送时间段 | 显示可配送时间范围 |
| 9 | 点击"提交订单" | 跳转支付页面 |
| 10 | 完成支付（模拟/微信） | 订单状态变为"待接单" |
| 11 | 查看订单列表 | 显示所有订单及状态 |
| 12 | 点击订单查看详情 | 显示配送跟踪信息 |
| 13 | 收到配送到达通知 | 小程序推送消息 |
| 14 | 确认收货/签收 | 订单状态变为"已完成" |
| 15 | 对订单评价（可选） | 提交评价，更新商品评分 |

#### 商家操作流程

| 步骤 | 操作 | 系统响应 |
|------|------|----------|
| 1 | 打开Web管理后台，登录 | 进入数据看板 |
| 2 | 添加/编辑商品 | 填写商品信息，上传图片，设置分类、价格、库存 |
| 3 | 查看新订单 | 订单列表高亮提示，数量统计 |
| 4 | 点击订单，接单确认 | 订单状态变为"已接单" |
| 5 | 将订单分配给骑手 | 选择骑手，发送通知 |
| 6 | 标记骑手已取货 | 订单状态变为"配送中" |
| 7 | 处理售后/退款 | 审核退款请求 |
| 8 | 查看数据看板 | 今日订单、销售额、待配送订单数 |
| 9 | 管理配送时间段 | 添加/编辑/删除可配送时间 |
| 10 | 发布公告 | 展示在用户端首页 |

#### 骑手操作流程

| 步骤 | 操作 | 系统响应 |
|------|------|----------|
| 1 | 打开骑手端，登录 | 显示待取货订单列表 |
| 2 | 点击"接单"领取配送任务 | 订单分配给该骑手，状态变为"待取货" |
| 3 | 前往商家仓库取货 | 点击"已到商家" |
| 4 | 商家确认骑手已取货 | 订单状态变为"配送中" |
| 5 | 查看配送路线/导航 | 地图展示客户位置 |
| 6 | 到达客户门口 | 点击"已到达" |
| 7 | 客户签收 | 点击"确认送达"，订单完成 |
| 8 | 查看历史配送记录 | 统计配送单数、收入 |

## 四、技术栈选择

### 4.1 整体架构

```
┌─────────────────────────────────────────────────────────────────┐
│                         客户端（用户）                           │
│                    微信小程序（原生开发）                          │
│              WXML + WXSS + JavaScript + Miniprogram API          │
└─────────────────────────────────────────────────────────────────┘
                                  │
                                  │ HTTPS API
                                  ▼
┌─────────────────────────────────────────────────────────────────┐
│                        后端服务（Flask）                          │
│                      Python 3.x + Flask                          │
│                    路由: Flask Blueprint                         │
│                   ORM: Flask-SQLAlchemy                         │
│                    认证: JWT Token                               │
└─────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─────────────────────────────────────────────────────────────────┐
│                        数据存储层                                 │
│                      MySQL 5.7+ (生产环境)                       │
│                      SQLite (开发环境)                           │
└─────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─────────────────────────────────────────────────────────────────┐
│                        文件存储                                  │
│                   七牛云 / 阿里云 OSS                             │
│              (商品图片、轮播图、用户头像)                          │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 技术选型

| 组件 | 选择 | 理由 |
|------|------|------|
| **后端框架** | Flask | 高效简洁，适合快速开发 |
| **小程序端** | 原生开发 | 无框架依赖，适合 Claude Code 理解，体积小 |
| **商家后台** | Web 响应式 | 手机浏览器即可访问，无需安装 |
| **骑手端** | 小程序独立分包 | 与客户端共用，减少开发成本，独立入口 |
| **数据库** | MySQL | 多端访问、后期扩展能力强 |
| **文件存储** | 七牛云 | 减轻服务器压力，CDN 加速 |
| **支付** | 模拟支付（Phase1）→ 微信支付（Phase2） | MVP 阶段快速验证 |
| **地图** | 腾讯地图 SDK | 小程序原生支持 |

## 五、UI/UX 设计规范

### 5.1 设计理念

**核心关键词**：新鲜 · 本地 · 温暖 · 朴实

**设计方向**：田园清新风格，融入自然元素，营造社区邻里的亲近感

### 6.2 数据表详细设计

#### 6.2.1 用户表 (user)

| 字段名 | 类型 | 约束 | 说明 |

| avatar_url | VARCHAR(256) | | 头像URL |

| status | INTEGER | NOT NULL, DEFAULT 1 | 状态: 1正常 0禁用 |
| created_at | DATETIME | NOT NULL | 创建时间 |
| updated_at | DATETIME | NOT NULL | 更新时间 |

```sql
CREATE TABLE user (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    openid VARCHAR(64) UNIQUE NOT NULL,
    nickname VARCHAR(64),
    avatar_url VARCHAR(256),
    phone VARCHAR(20),
    role VARCHAR(20) NOT NULL DEFAULT 'customer',

    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
```

#### 6.2.6 订单主表 (order)

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PK, AUTO | 订单ID |
| order_no | VARCHAR(32) | UNIQUE, NOT NULL | 订单编号 |

| address_id | INTEGER | FK(address.id), NOT NULL | 收货地址 |
| total_amount | DECIMAL(10,2) | NOT NULL | 订单总金额 |
| discount_amount | DECIMAL(10,2) | DEFAULT 0 | 优惠金额 |
| pay_amount | DECIMAL(10,2) | NOT NULL | 实付金额 |
| pay_type | VARCHAR(20) | | 支付方式: wechat/simulate/cash |
| pay_time | DATETIME | | 支付时间 |
| status | INTEGER | NOT NULL, DEFAULT 0 | 订单状态 |

**订单状态说明 (status)**:

```sql
CREATE TABLE order (

    discount_amount DECIMAL(10,2) DEFAULT 0,
    pay_amount DECIMAL(10,2) NOT NULL,
    pay_type VARCHAR(20),
    pay_time DATETIME,
    status INTEGER NOT NULL DEFAULT 0,
    remark VARCHAR(500),
    cancel_reason VARCHAR(200),
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
```

## 八、API接口设计

### 8.1 基础信息

**Base URL**: `https://your-domain.com/api/v1`

**认证方式**: JWT Token
- 请求头: `Authorization: Bearer <token>`
- Token 有效期: 7天
- Refresh Token: 有效期30天

**统一响应格式**:
```json
{
    "code": 0,
    "message": "success",
    "data": {}
}
```

**错误码**:
| code | 说明 |
|------|------|
| 0 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录/Token过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器错误 |

```python
# backend/utils/decorators.py

import jwt
from functools import wraps
from flask import request, jsonify, current_app

def token_required(f):
    """验证 JWT Token 中间件"""
    @wraps(f)
    def decorated(*args, **kwargs):
        token = None
        
        # 从请求头获取 Token
        if 'Authorization' in request.headers:
            auth_header = request.headers['Authorization']
            try:
                token = auth_header.split(' ')[1]
            except IndexError:
                return jsonify({'code': 401, 'message': 'Token格式错误'}), 401
        
        if not token:
            return jsonify({'code': 401, 'message': '请先登录'}), 401
        
        try:
            # 解码 Token
            payload = jwt.decode(
                token, 
                current_app.config['SECRET_KEY'], 
                algorithms=['HS256']
            )
            request.user_id = payload['user_id']
            request.user_role = payload.get('role', 'customer')
        except jwt.ExpiredSignatureError:
            return jsonify({'code': 401, 'message': 'Token已过期'}), 401
        except jwt.InvalidTokenError:
            return jsonify({'code': 401, 'message': 'Token无效'}), 401
        
        return f(*args, **kwargs)
    
    return decorated


def admin_required(f):
    """管理员权限验证"""
    @wraps(f)
    @token_required
    def decorated(*args, **kwargs):
        if request.user_role != 'merchant':
            return jsonify({'code': 403, 'message': '无权限访问'}), 403
        return f(*args, **kwargs)
    
    return decorated


def rider_required(f):
    """骑手权限验证"""
    @wraps(f)
    @token_required
    def decorated(*args, **kwargs):
        if request.user_role != 'rider':
            return jsonify({'code': 403, 'message': '无权限访问'}), 403
        return f(*args, **kwargs)
    
    return decorated
```

### 11.3 接口安全

#### 请求频率限制

```python
# backend/utils/rate_limit.py

from flask import request, jsonify
from functools import wraps
import time
from collections import defaultdict

# 存储请求记录（生产环境应使用 Redis）
request_records = defaultdict(list)

def rate_limit(max_requests=60, window=60):
    """
    请求频率限制装饰器
    
    Args:
        max_requests: 最大请求次数
        window: 时间窗口（秒）
    """
    def decorator(f):
        @wraps(f)
        def decorated(*args, **kwargs):
            # 获取用户标识（优先 IP，其次 user_id）
            identifier = request.remote_addr
            if hasattr(request, 'user_id'):
                identifier = f"user_{request.user_id}"
            
            now = time.time()
            
            # 清理过期记录
            request_records[identifier] = [
                t for t in request_records[identifier]
                if now - t < window
            ]
            
            # 检查频率
            if len(request_records[identifier]) >= max_requests:
                return jsonify({
                    'code': 429,
                    'message': '请求过于频繁，请稍后再试'
                }), 429
            
            # 记录请求
            request_records[identifier].append(now)
            
            return f(*args, **kwargs)
        
        return decorated
    
    return decorator


# 使用示例
```

```python
# backend/utils/security.py

import hashlib
import hmac

def hash_password(password, salt=None):
    """密码哈希加密"""
    if salt is None:
        salt = os.urandom(32)
    
    pwd_hash = hashlib.pbkdf2_hmac(
        'sha256',
        password.encode('utf-8'),
        salt,
        100000  # 迭代次数
    )
    
    return salt.hex() + pwd_hash.hex()


def verify_password(password, hashed):
    """验证密码"""
    salt = bytes.fromhex(hashed[:64])
    stored_hash = hashed[64:]
    
    pwd_hash = hashlib.pbkdf2_hmac(
        'sha256',
        password.encode('utf-8'),
        salt,
        100000
    )
    
    return hmac.compare_digest(pwd_hash.hex(), stored_hash)


def mask_phone(phone):
    """手机号脱敏"""
    if not phone or len(phone) != 11:
        return phone
    return phone[:3] + '****' + phone[7:]


def mask_name(name):
    """姓名脱敏"""
    if not name:
        return name
    if len(name) == 1:
        return '*'
    if len(name) == 2:
        return name[0] + '*'
    return name[0] + '*' + name[-1]
```

```python
# backend/utils/logging.py

import logging
import re

class SensitiveDataFilter(logging.Filter):
    """日志敏感信息过滤"""
    
    SENSITIVE_PATTERNS = [
        (r'"phone"\s*:\s*"[^"]+"', '"phone":"***"'),
        (r'"id_card"\s*:\s*"[^"]+"', '"id_card":"***"'),
        (r'"password"\s*:\s*"[^"]+"', '"password":"***"'),
        (r'"token"\s*:\s*"[^"]+"', '"token":"***"'),
        (r'"bank_card"\s*:\s*"[^"]+"', '"bank_card":"***"'),
    ]
    
    def filter(self, record):
        record.msg = self.mask_sensitive(record.msg)
        if record.args:
            record.args = tuple(
                self.mask_sensitive(str(arg)) 
                for arg in record.args
            )
        return True
    
    def mask_sensitive(self, text):
        for pattern, replacement in self.SENSITIVE_PATTERNS:
            text = re.sub(pattern, replacement, text)
        return text
```

```sql
CREATE DATABASE IF NOT EXISTS dayan_vegetable DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

USE dayan_vegetable;

-- 用户表
CREATE TABLE IF NOT EXISTS `user` (
    `id` INTEGER PRIMARY KEY AUTOINCREMENT,
    `openid` VARCHAR(64) UNIQUE NOT NULL,
    `nickname` VARCHAR(64),
    `avatar_url` VARCHAR(256),
    `phone` VARCHAR(20),
    `role` VARCHAR(20) NOT NULL DEFAULT 'customer',
    `status` INTEGER NOT NULL DEFAULT 1,
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 分类表
CREATE TABLE IF NOT EXISTS `category` (
    `id` INTEGER PRIMARY KEY AUTOINCREMENT,
    `name` VARCHAR(50) NOT NULL,
    `icon` VARCHAR(256),
    `sort_order` INTEGER DEFAULT 0,
    `status` INTEGER DEFAULT 1,
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 商品表
CREATE TABLE IF NOT EXISTS `product` (
    `id` INTEGER PRIMARY KEY AUTOINCREMENT,
    `category_id` INTEGER,
    `name` VARCHAR(100) NOT NULL,
    `subtitle` VARCHAR(200),
    `price` DECIMAL(10,2) NOT NULL,
    `original_price` DECIMAL(10,2),
    `unit` VARCHAR(20) NOT NULL,
    `stock` INTEGER NOT NULL DEFAULT 0,
    `image` VARCHAR(256),
    `images` TEXT,
    `description` TEXT,
    `tags` VARCHAR(100),
    `sort_order` INTEGER DEFAULT 0,
    `status` INTEGER DEFAULT 1,
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (`category_id`) REFERENCES `category`(`id`)
);

-- 收货地址表
CREATE TABLE IF NOT EXISTS `address` (
    `id` INTEGER PRIMARY KEY AUTOINCREMENT,
    `user_id` INTEGER NOT NULL,
    `name` VARCHAR(50) NOT NULL,
    `phone` VARCHAR(20) NOT NULL,
    `province` VARCHAR(50) NOT NULL,
    `city` VARCHAR(50) NOT NULL,
    `district` VARCHAR(50) NOT NULL,
    `detail` VARCHAR(200) NOT NULL,
    `building` VARCHAR(50),
    `room` VARCHAR(50),
    `latitude` DECIMAL(10,8),
    `longitude` DECIMAL(11,8),
    `is_default` INTEGER DEFAULT 0,
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (`user_id`) REFERENCES `user`(`id`)
);

-- 购物车表
CREATE TABLE IF NOT EXISTS `cart` (
    `id` INTEGER PRIMARY KEY AUTOINCREMENT,
    `user_id` INTEGER NOT NULL,
    `product_id` INTEGER NOT NULL,
    `quantity` INTEGER NOT NULL DEFAULT 1,
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (`user_id`) REFERENCES `user`(`id`),
    FOREIGN KEY (`product_id`) REFERENCES `product`(`id`),
    UNIQUE(`user_id`, `product_id`)
);

-- 订单主表
CREATE TABLE IF NOT EXISTS `order` (
    `id` INTEGER PRIMARY KEY AUTOINCREMENT,
    `order_no` VARCHAR(32) UNIQUE NOT NULL,
    `user_id` INTEGER NOT NULL,
    `address_id` INTEGER NOT NULL,
    `total_amount` DECIMAL(10,2) NOT NULL,
    `discount_amount` DECIMAL(10,2) DEFAULT 0,
    `pay_amount` DECIMAL(10,2) NOT NULL,
    `pay_type` VARCHAR(20),
    `pay_time` DATETIME,
    `status` INTEGER NOT NULL DEFAULT 0,
    `remark` VARCHAR(500),
    `cancel_reason` VARCHAR(200),
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (`user_id`) REFERENCES `user`(`id`),
    FOREIGN KEY (`address_id`) REFERENCES `address`(`id`)
);

CREATE TABLE IF NOT EXISTS `order_item` (
    `id` INTEGER PRIMARY KEY AUTOINCREMENT,

    `product_name` VARCHAR(100) NOT NULL,
    `product_image` VARCHAR(256),
    `price` DECIMAL(10,2) NOT NULL,
    `quantity` INTEGER NOT NULL,
    `subtotal` DECIMAL(10,2) NOT NULL,
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (`order_id`) REFERENCES `order`(`id`),
    FOREIGN KEY (`product_id`) REFERENCES `product`(`id`)
);

CREATE TABLE IF NOT EXISTS `delivery` (
    `id` INTEGER PRIMARY KEY AUTOINCREMENT,

    `note` VARCHAR(200),
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (`order_id`) REFERENCES `order`(`id`),
    FOREIGN KEY (`rider_id`) REFERENCES `user`(`id`),
    FOREIGN KEY (`delivery_slot_id`) REFERENCES `delivery_slot`(`id`)
);
```

## 十五、常见问题 FAQ

### 15.1 开发问题

**Q: 小程序提示"域名不在合法域名列表"？**
```
A: 开发阶段在微信开发者工具中勾选"不校验合法域名"。
   生产阶段需在微信公众平台配置 request 合法域名。
```

**Q: 微信登录失败，提示 invalid code？**
```
A: 检查 appid 和 appsecret 是否正确，确保在微信公众平台获取了正确的登录凭证。
```

**Q: 数据库连接失败？**
```
A: 检查 MySQL 服务是否启动，确认数据库用户权限和密码配置正确。
```

**Q: 图片上传失败？**
```
A: 检查七牛云配置是否正确，确认 bucket、access_key、secret_key 有效。
```

### 15.2 运维问题

**Q: Docker 容器无法启动？**
```
A: 执行 docker-compose logs <service_name> 查看详细日志。
   常见问题：端口冲突、配置文件错误、挂载目录权限不足。
```

**Q: 服务响应很慢？**
```
A: 1. 检查服务器资源使用情况（CPU、内存、磁盘IO）
   2. 检查数据库查询性能，添加必要的索引
   3. 启用 Redis 缓存热点数据
   4. 使用 APM 工具定位性能瓶颈
```

**Q: 如何升级服务？**
```
A: 
   # 1. 拉取最新代码
   git pull origin main
   
   # 2. 重新构建镜像
   docker-compose -f docker-compose.prod.yml build backend
   
   # 3. 滚动更新
   docker-compose -f docker-compose.prod.yml up -d --no-deps backend
   
   # 4. 检查日志确认升级成功
   docker-compose -f docker-compose.prod.yml logs -f backend
```

**Q: 数据库如何备份？**
```
A: 
   # 定期自动备份（添加到 crontab）
   0 2 * * * docker exec dayan-vegetable_db_1 mysqldump -uuser -ppass dayan_vegetable > /backup/dayan_$(date +\%Y\%m\%d).sql
   
   # 手动备份
   docker exec -i dayan-vegetable_db_1 mysqldump -uuser -ppass dayan_vegetable > backup.sql
```
